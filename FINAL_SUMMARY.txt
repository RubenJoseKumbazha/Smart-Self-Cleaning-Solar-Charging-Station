API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

RELAY CONTROL (via Backend):

  Get State:
    curl http://localhost:5000/api/relay/state
    → {"state":"ON","value":1,"timestamp":"2026-04-20T..."}

  Set State:
    curl -X POST http://localhost:5000/api/relay/state \
      -H "Content-Type: application/json" \
      -d '{"state":"ON"}'
    → {"state":"ON","value":1,"timestamp":"...","message":"..."}

  Toggle:
    curl -X POST http://localhost:5000/api/relay/toggle
    → {"state":"OFF","value":0,"timestamp":"...","message":"..."}

LEGACY RELAY (for ESP32):
  
  Get:  curl http://localhost:8000/getRelay.php
        → "0" or "1"
  
  Set:  curl "http://localhost:8000/setRelay.php?state=1"
        → "OK"
